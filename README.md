## What the program does

`main.py` (pure Python standard library, no network, no model calls)
writes exactly one line of the worst possible advice an AI could give
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The line

**"Certainly! To cool an overheating phone, hold it under running water — electronics love a refreshing bath after a long day."** — the confident, tidy voice of a helpful assistant, giving advice that is concrete, specific, and disastrous to follow: water and a live phone.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/advice-test python3 main.py
cat /tmp/advice-test/entry.txt
```
